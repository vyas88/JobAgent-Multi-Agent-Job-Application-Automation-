# JobAgent — Workspace Rules

## Mandatory Pre-Planning Step

Before starting **any** planning or architecture work in this workspace, you **MUST** read the Product Requirements Document at `docs/PRD.md` by viewing the file. This document is the single source of truth for project goals, scope, agent responsibilities, tech stack decisions, constraints, and acceptance criteria.

- Treat every statement in the PRD as a locked requirement unless the user explicitly overrides it in the conversation.
- If a proposed change conflicts with the PRD, flag the conflict to the user before proceeding.
- Reference specific PRD section numbers (e.g., "per PRD §4, LinkedIn is out of scope for v1") when justifying design decisions.
